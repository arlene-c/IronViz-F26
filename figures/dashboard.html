Glossary

Request / call
One time a program asks an AI model for an answer.
Token
A small piece of text (about ¾ of a word). AI use is measured and billed in tokens.
Fully completed
The request was admitted and finished without being cut short.
Cut short
Admitted, but the answer hit the 1,024-token output cap. This happens even with a full budget.
Refused
Not admitted because the rule judged there wasn't enough money for it.
Caching
Reusing part of a prompt the model has seen recently. Cached tokens cost less.
Premium model
The larger, more expensive models: gpt-4o, o1-preview and gemini-1.5-pro.
Testing teams
org-engineering-dev and prj-ai-sandbox-testing, the two teams that build and experiment.
First come, first served
Approve every request until the shared budget runs out.
Equal quotas
Each team gets an equal slice of the budget; no sharing.
Training-week quotas
Each team's slice follows its spending in the first (training) week; no sharing.
Adaptive sharing
Each team has a protected slice, and can borrow money other teams aren't using.
Spend pacing
Approve a request only if total spending stays near a straight-line plan for the month.
Cost threshold
Refuse any single request expected to cost more than a limit tuned on the training week.
Budget %
Share of the modeled cost of serving every request ($) available to spend.
